IMPORTANT NOTES
1. Execute DCL questions using an account with sufficient privileges to create users and grant or revoke permissions.
2. Use separate MySQL connections to test each user's permissions.
3. Use straight single quotes in SQL statements, for example:
   CREATE USER 'user1'@'localhost' IDENTIFIED BY 'StrongPasswordHere';
4. Use strong passwords in real applications; simple passwords should be used only in controlled demonstrations.
5. CREATE TABLE ... AS SELECT copies the query result into a new table. It does not keep the copy synchronized, and the new table generally does not inherit the original table's indexes and constraints.
6. AUTO_INCREMENT values are generated automatically. Deleted IDs are not necessarily reused.
7. Generated columns are calculated from their expressions. Update the underlying columns instead of assigning values directly to generated columns.
8. Privileges depend on the grants and roles applicable to the MySQL account.
